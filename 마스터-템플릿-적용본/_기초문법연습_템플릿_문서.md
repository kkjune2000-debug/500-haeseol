## 2. 종합 활용표 (`table.cjt`)

**열**: `의미` | `힌트` | `가다` | `먹다` | `하다` | `좋다`

- 헤더 `힌트<br><small>Hint</small>` — 옛 "어미 · Ending"에서 개명.
- 기준 단어 헤더는 **한국어만** (`가다`/`먹다`/`하다`/`좋다`). ⚠️ 밑에 영어(`go · V` 등)·품사 표기 **삭제**.
- `의미` 칸: 한국어 의미 라벨. 군더더기 제거(예: `현재 평서`→`현재`). **청유 계열 표기**: `청유`(-ㅂ시다) · `청유 의문`(-ㄹ까요?) · `청유 의문`(-ㄹ래요?, 옛 "의향") · `청유 부정`(-지 맙시다) · `청유 의문 부정`(-지 말까요?, 옛 "청유 부정 의문").
- ⚠️ **예시(샘플) 행 마커 없음** (옛 첫 행 "예시" 라벨 삭제).

**"?" 가림 (자가 점검)**: `힌트(td.e)` + `활용형(td.v / td.a)` 셀을 모두 가림.
- 셀 = `<td class="q-cell"><span class="q-text" onclick="qHide(this)">정답</span><button class="q-ans" onclick="qReveal(this)">?</button></td>` 형태로 래핑(JS 자동).
- 표 위에 `.ans-bar`(💡 모두 보기 / 🔄 다시 가리기, `qAll`).
- `@media print` 시 정답 표시.

## 3. Writing Test (`table.cjt.neg-test`)

- 같은 6열. `가다~좋다` 칸은 **입력칸**(`<input class="neg-input" data-ans="…" oninput="negCheck(this)">`), `*`이면 `—`(td.na).
- ⚠️ **`힌트(td.e)` 칸도 "?"로 가림** (종합 활용표와 동일).
- 버튼: 🔄 초기화(`negReset`) · ✅ 채점(`negGrade`) · 💡 정답(`negReveal`). 점수 `/ N`.

## 4. 데이터 (스크립트 `DRILL` 배열)

```
DRILL = [ [eng, 의미(ko), 어미, 가다형, 먹다형, 하다형, 좋다형], … ]
```
- `*` = 해당 없음 → 표에서 `—`(td.na). (형용사 좋다가 진행/명령/청유/희망 등 못 쓰는 칸)
- `colCls = ["v","v","v","a"]` — 가다·먹다·하다=동사(파랑틴트), 좋다=형용사(보라틴트).
- `refBody`(읽기)와 `drillBody`(쓰기)를 **같은 `head`(의미+힌트)** 로 동시 생성.
- `LS` 배열 → Look & Speak 12카드. `emPairs` → Sentence Matching.
