# 부록 1 · 숫자 — 표 색·스타일 문서 (Number Tables — Color & Style Guide)

대상 파일: `부록 1 _ 숫자.html`
최종 정리: 2026-06-16

---

## 1. 색 체계 (3-색 규칙)

모든 숫자 표는 **세 가지 의미색**으로 통일한다. "왼쪽=수, 오른쪽=한국어"가 한눈에 구분되도록 한다.

| 의미 | 색(계열) | 쓰임 |
|---|---|---|
| **분홍 (Pink)** | 숫자 · 기호 · 식 (수 그 자체) | 숫자 열, 기호(+−×÷), 연산식 |
| **연두 (Yellow-green)** | 한국어 읽기 | 읽기 열, 한자어/고유어, 기호 이름 |
| **회색 (Neutral)** | 영어 뜻 · 보조 | 영어 Meaning, 중립 칸 |

> 핵심 흐름: **분홍(수/기호) → 연두(한국어 읽기)**. 영어 뜻은 회색으로 분리.

## 2. 팔레트 (HEX)

### 분홍 (수·기호·식)
- 칸 배경 `#fdf2f8`
- 헤더 배경 `#fce7f3` · 헤더/라벨 글자 `#9d174d`
- 숫자 글자(가독성) `#0f172a`

### 연두 (한국어 읽기) — 옅은→짙은 3단계
- 칸 배경 `#f7fee7` (연함) · `#edfacb` (중간) · `#e3f3c2` (짙음)
- 헤더 배경 `#e9f7c5` · `#ddf2a8` · `#d0ea9a`
- 글자 `#3f6212` (짙은 올리브그린)

### 회색 (영어 뜻·중립)
- 칸 배경 `#f8fafc` · 헤더 배경 `#e2e8f0`
- 글자 `#475569`(본문) · `#334155`(헤더)

### 공통
- 테두리 `#cbd5e1`
- 만·억·조 단위 라벨 글자 `#b45309` (앰버)

## 3. 표별 적용

| 표 | 구성 | 왼쪽(분홍) | 오른쪽(연두) |
|---|---|---|---|
| **s1** (1~12 · 19~100) | 3행 | 숫자 `#fdf2f8` | 한자어 `#f7fee7` / 고유어 `#e3f3c2` |
| **s2** (101~1,234) | 2행 | 숫자 `#fdf2f8` | 읽기 `#edfacb` |
| **s3** (만 단위) | 2열 | 숫자 `#fdf2f8` | 읽기 `#f7fee7` |
| **s4** (백만~조) | 2열 | 숫자 `#fdf2f8` | 읽기 `#edfacb` |
| **s5** (큰 수 연습) | 2열 | 숫자 `#fdf2f8` | 읽기 `#e3f3c2` |
| **s6** (연산·분수·온도) | 2열 | 표현 `#fdf2f8` | 읽기 `#f7fee7` |
| **s7** (시간·날짜) | 2열 | 시간 `#fdf2f8` | 읽기 `#edfacb` |
| **symt** (연산·기호) | 5열 | 기호·연산 `#fdf2f8` | 이름·읽기 `#f7fee7`/`#edfacb` (뜻=회색 `#f8fafc`) |

> s3~s7·symt의 읽기 열은 표마다 연두 단계를 조금씩 달리해 표를 구분한다.

## 5. 구조·표기 규칙

- **칸 높이**: `.numt td` padding `12px 5px` (`.numt.wide`는 `10px 3px`).
- **큰 수 표기**: 콤마(3자리, 원래 위치) + 슬래시(4자리=만 단위) 동시 표기. 예) `12,34/5,678`.
- **만·억·조 라벨**: 각 `/` 아래 작은 글씨로 만·억·조(오른쪽부터). `.msep`(inline-flex 세로) + `.munit`(0.5rem, `#b45309`, margin-top 5px).
- **분수**: 분모(아래)부터 읽음 — `3/4 → 사분의 삼`.
- **읽기 vs 데이터 분리**: 참조표 읽기 셀에만 표기용 `/`·라벨 적용. 받아쓰기·매칭의 정답 데이터(JS 배열)는 콤마 그대로 두어 채점에 영향 없음.

## 6. symt (연산·기호 표) 핵심 CSS

```css
.symt{width:100%;border-collapse:collapse;font-size:0.88rem;margin:8px 0 16px;}
.symt th{padding:9px 8px;border:1px solid #cbd5e1;font-weight:800;text-align:center;}
.symt th:nth-child(1),.symt th:nth-child(4){background:#fce7f3;color:#9d174d;}   /* 기호·연산 = 분홍 */
.symt th:nth-child(2),.symt th:nth-child(5){background:#e9f7c5;color:#3f6212;}   /* 이름·읽기 = 연두 */
.symt th:nth-child(3){background:#e2e8f0;color:#334155;}                          /* 뜻 = 회색 */
.symt td{padding:9px 8px;border:1px solid #cbd5e1;vertical-align:middle;text-align:center;}
.symt td:first-child{font-weight:900;font-size:1.05rem;color:#0f172a;background:#fdf2f8;width:11%;}      /* 기호 */
.symt td:nth-child(2){font-weight:800;color:#3f6212;background:#f7fee7;width:17%;}                       /* 이름 */
.symt td:nth-child(3){text-align:center;color:#475569;font-size:0.85rem;width:20%;background:#f8fafc;}   /* 뜻 */
.symt td:nth-child(4){text-align:center;color:#0f172a;font-weight:700;font-size:0.85rem;width:20%;background:#fdf2f8;} /* 연산 */
.symt td:nth-child(5){text-align:left;color:#3f6212;font-size:0.85rem;background:#edfacb;}               /* 읽기 */
```

열 순서: **기호(분홍) · 이름(연두) · 뜻(회색) · 연산(분홍) · 읽기(연두)**
→ "기호→이름", "연산→읽기" 두 쌍이 모두 **분홍→연두**(수/기호 → 한국어) 흐름.
