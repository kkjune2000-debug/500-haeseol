## 1. 분할 원칙 — 어미를 결정하는 요인으로 나눈다
| 시제 | 어미 결정 요인 | 분할 방식 |
|---|---|---|
| **현재형** | 받침 | **A 받침없음 / B 하다 / C 받침있음 / D ㄹ받침** (4) |
| **과거형** | 마지막 모음(모음조화) | **규칙(밝은+어두운 통합) / 줄임 / 하다 / 불규칙** (4) |
| **미래형** | 받침 | **A 받침없음 / B 하다 / C 받침있음 / D ㄹ받침 / 불규칙** (5) |

핵심 판단:
- **받침으로 결정**되는 현재·미래 → 받침별 분리(현재 ↔ 미래 1:1 대응).
- **하다는 모든 시제에서 별도 파일**, 순서는 항상 **받침없음 바로 다음(Ⓑ)**. 현재·미래에서 하다는 문법적으론 받침없음 규칙 그대로지만(하+ㅂ니다=합니다, 하+ㄹ것=할것), "명사+하다 최대 어휘군"으로 framing해 분리(2026-06-11 결정).
- **모음으로 결정**되는 과거 규칙(밝은/어두운)은 한 비교 단위라 **한 파일**에 둔다.
- **불규칙은 항상 별도 파일.**
- **배지(🅐🅑🅒…/🅰🅱🅲…)는 시제 시리즈 전역 일련번호**: 하다가 Ⓑ로 들어오면 받침있음=Ⓒ, ㄹ받침=Ⓓ, 미래 불규칙 ㄷ·ㅂ·ㅅ=🅴🅵🅶로 시프트.

## 3. 파일 내부 템플릿 (각 규칙/불규칙 파일 공통 순서)
1. **h1** `시제 N · ○○형 — 라벨` + 영어 부제(`<p class="subtitle">`).
2. **규칙 설명** — `h4.rule-h`(파랑/슬레이트 그라데이션) + 한국어/영어 한 줄 병기.
3. **(불규칙만)** `conj-ir` 3단계 가로 흐름 카드(①조건→②변화→③결과).
4. **요약 카드(rule-summary)** — **반드시 직접 만들기 위에.** **누적식(2026-06-12)**: A파일=Ⓐ만, B파일=Ⓐ+Ⓑ, C파일=Ⓐ~Ⓒ, 마지막 파일=전체. 제목은 부분이면 "요약 · Summary", 전체만 "전체 요약 · Summary". **현재형·과거형·미래형 모두 적용** — 과거형 A~C는 rule-summary 누적 카드(Ⓐ규칙 았/었·Ⓑ줄임·Ⓒ하다), 과거형 D는 기존 9칸 sp-card 그리드가 전체 요약 역할(유지). 인트로 파일(시제_0·조사_0)의 요약은 항상 전체.
5. **직접 만들기 `pr80`** — 컴팩트 헤더 `<h3 class="pr80-h">✍️ ○○ 직접 만들기 · Make the ○○ form</h3>`.
6. **퀴즈 1 · 플래시 카드** (`fc-grid`, 플립 카드 + 🔊 TTS).
7. **퀴즈 2 · 쓰기** (`pt-table` 타이핑, 점수/정답/초기화 + "정답!" 뱃지 5초).
8. **객관식**은 `.quiz-box{display:none !important;}`로 숨김(코드는 유지).

## 4. 스타일·규칙 (필수 준수 — 메모리 피드백 반영)
- **pr80-h**: `margin:30px 0 2px; font-size:1.04rem; font-weight:800;` + 시제 테마색. 큰 제목+부제+안내문단 형식 금지(컴팩트 h3만).
- **플로우차트(conj-*)**: 가로 디자인. `>720` 데스크톱 / `≤720` 컴팩트 가로 / `≤460` 세로 폴백.
- **rule-h 한글 헤더**엔 영어 해석 한 줄 병기(`<span style="display:block;font-size:0.82rem;...">`).
- **받침 라벨**: `No 받침`(빨강 #dc2626) / `With 받침`(초록 #16a34a). 패턴 박스에서 받침 X/O 표기 대체.
- **어미 칩**: `white-space:nowrap`, 한국어 `word-break:keep-all`. "어간 + 어미"는 한 줄.
- **영어 비교 금지**(다른 언어 번역 예정). 영어 병기줄은 단순 번역으로만.
- **예문 격식체**(-ㅂ니다/습니다), "예시"→"예문".
- **퀴즈 번호**: 플래시=퀴즈1, 쓰기=퀴즈2(객관식 숨김이므로).
- **단어 목록 공유**: 만들기·플래시·쓰기가 같은 단어를 쓰도록 `window.TWORDS` 전역 + `ruleOf()` 필터.
- **gstep 카드표**: 4분류 색(문장구조 파랑/서술어 보라/부사어 초록/기타 앰버) — 시제는 파랑.

## 5. 분할 작업 절차 (기술 — PowerShell 줄 슬라이스)
원본을 통째로 복사하지 말고 **필요한 구간만 이어 붙인다**:
```
새 파일 = head(1~16: 기본+mc CSS, body·container 열기)
        + 새 제목(h1+부제)
        + fc/pt/wqg CSS 블록(원본의 첫 <style> 블록)
        + 해당 규칙/불규칙 섹션 + 요약 + 만들기 + 플래시 + 쓰기
        + 꼬리말(footer + speakKorean + wq-badge 전역 스크립트 + </body></html>)
```
- `Get-Content -LiteralPath $f -Encoding UTF8`로 읽고, 배열 슬라이스(`$L[a..b]`)를 `+`로 연결.
- 출력은 **UTF-8 no BOM**: `[System.IO.File]::WriteAllLines($dst,$out,(New-Object System.Text.UTF8Encoding($false)))`.
- 한글 제목은 자리표시자(`___H1___`)로 넣은 뒤 **Edit 툴**로 교체(명령줄 한글 인코딩 위험 회피).
- 경계 줄은 슬라이스 전에 반드시 출력해 확인.
- OneDrive 동기화로 "modified since read" 발생 시 직전 구간 재-Read 후 Edit.

### 단어 분배 (ruleOf)
```js
function ruleOf(base){
  var stem = base.replace(/다$/,'');
  if(base.endsWith('하다')) return 'H';      // 하다 — 미래형에선 받침없음(A)과 동일 취급
  var last = stem.length-1;
  var c = stem.charCodeAt(last) - 0xAC00;
  if(c < 0 || c > 11171) return 'C';
  var jong = c % 28;
  if(jong === 0) return 'V';   // 받침없음 → A
  if(jong === 8) return 'L';   // ㄹ받침 → C
  return 'C';                  // 받침있음 → B
}
```
- 미래형 A(받침없음)에는 `V`+`H`+ ㅡ/르(어간이 모음으로 끝남) 모두 규칙으로 포함.
- 불규칙(ㄷ·ㅂ·ㅅ)은 따로 데이터로 관리(ruleOf로 안 잡힘 — 사전 지정).

### 조사 파일 템플릿 (B 을/를에서 확립 → 전 파일 적용 완료 2026-06-12)
각 조사 파일 = **설명 → ① 분기 흐름 카드 → (예시 표) → ② ✍️ 직접 만들기 → ③ 퀴즈 플래시 카드** 순.
1. **분기 흐름 카드** (conj-rule 이식, 파랑 r-a): `단어 ➜ [분기 배지] + [조사 칩] ➜ 결과`.
   - 받침 분기(A 은/는·이/가, B 을/를, D 와/과, E 나/이나): 배지 `받침 X`(빨강 .pb-x)/`받침 O`(초록 .pb-o). A는 카드 2개(은/는=r-a 파랑, 이/가=r-b 초록).
   - 의미 분기(C 에게/에): 배지 `사람·동물`(파랑 .pb-p)/`사물·식물`(앰버 .pb-t).
   - 무변화(F 에, G 에서): 배지 없이 `+ 에`/`+ 에서` 칩만.
2. **직접 만들기** (pr80 조사 버전): 단어+조사 통째 타이핑, 행별 ✓정답·💡설명(분기 배지+규칙+유도+영어), 받침은 `batchim()` 자모 계산 자동판정. 함수 접두사 `prJ*`, 데이터 `window.JWORDS` 공유. 12단어 기본.
3. **플래시 카드**: 앞=단어+영어, 뒤=분기 배지+결과+🔊TTS. A는 은/는·이/가 2단(fc-row-wrap statement/question).
- 구식 객관식은 만들기로 대체. 단 **G의 '에 vs 에서' 문장 객관식은 유지**(의미 대비 연습이라 타이핑으로 대체 불가) → G는 카드+객관식+플래시.
- F(에-시간)는 퀴즈가 없었음 → 만들기+플래시 신설로 해결.
- ✅ 조사_0 전체 요약표 → rule-summary 카드 2개(받침 분기 Ⓐ Ⓑ Ⓓ Ⓔ / 무변화·의미 Ⓒ Ⓕ Ⓖ) 완료(2026-06-12).
