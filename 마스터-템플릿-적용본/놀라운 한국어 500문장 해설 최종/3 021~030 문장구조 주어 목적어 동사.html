구조 3: 주어 + 목적어 + 동사
Subject + Object + Verb

주어 + 목적어 + 서술어는 한국어 문장 구조의 가장 일반적인 형태입니다. 그런데 목적어 다음의 서술어 자리에는 형용사가 올 수 없습니다(형용사는 목적어를 가질 수 없으니까요). 그래서 이 구조는 주어 + 목적어 + 동사로 바꿔 말할 수 있습니다.
Subject + Object + Predicate is the most common Korean sentence structure. But the predicate after the object cannot be an adjective (adjectives can't take an object), so this structure can be restated as Subject + Object + Verb.
주의할 점은 모든 동사 앞에 목적어가 오는 것은 아니라는 것입니다. 대부분의 동사(타동사)는 목적어를 갖지만, 목적어를 가질 수 없는 동사(자동사)도 있다는 점을 기억하세요.
Note, however, that not every verb takes an object: most verbs (transitive) do, but some (intransitive) cannot.
예) 목적어 O — 밥을 먹다, 책을 읽다, 영화를 보다 · 목적어 X — 가다, 오다, 자다, 웃다 (자동사는 목적어 없이: "저는 잡니다").
e.g., with object — 밥을 먹다 (eat rice), 책을 읽다 (read a book), 영화를 보다 (watch a movie); no object — 가다 (go), 오다 (come), 자다 (sleep), 웃다 (laugh): "저는 잡니다 = I sleep."

Special rule: 명사 + 하다 → 명사 + 을/를 하다
특별 규칙

한국어에는 명사 + 하다 동사들이 많이 있습니다 — 예: 운동하다, 청소하다, 공부하다. 명사 + 하다 동사는 명사 + 을/를 하다로 바꿔 쓸 수 있습니다.
Many Korean verbs are made of noun + 하다 (do) — for example, 운동하다 (exercise), 청소하다 (clean), 공부하다 (study). These noun + 하다 verbs can be rewritten as noun + 을/를 하다.
운동하다 → 운동을 하다  |  청소하다 → 청소를 하다
공부하다 → 공부를 하다  |  숙제하다 → 숙제를 하다
💡 Both forms are correct, but the split form (object + 하다) is what we practice here, because the goal of Structure 3 is the S + O + V pattern.
💡 두 형태 모두 맞습니다. 하지만 구조 3의 목표는 주어 + 목적어 + 서술어 패턴이므로 여기서는 나눠 쓰는 형태(목적어 + 하다)를 연습합니다.
