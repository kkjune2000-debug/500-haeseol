시제 3 · 미래형 — 불규칙

Tense 3 · Future Tense — Irregular (ㄷ·ㅂ·ㅅ)

📌 미래형 불규칙 (Future Tense Irregulars)

미래형 어미 '~을 것입니다'는 모음(ㅡ)으로 시작하므로, 받침이 모음 앞에서 변하는 일부 불규칙이 다시 나타납니다. 대상은 ㄷ · ㅂ · ㅅ 세 가지입니다.

The future ending '~을 것입니다' starts with a vowel (ㅡ), so the irregulars that change before vowels reappear: ㄷ, ㅂ, ㅅ.

참고: 'ㅡ 불규칙'과 '르 불규칙'은 어간이 모음으로 끝나기 때문에 미래형에서는 그냥 'ㄹ 것입니다'를 붙이는 규칙형이 됩니다. (예: 쓰다 → 쓸 것입니다, 다르다 → 다를 것입니다)

Note: 'ㅡ' and '르' irregulars have vowel-ending stems, so in the future tense they simply add 'ㄹ 것입니다' (regular). (e.g., 쓰다 → 쓸 것입니다, 다르다 → 다를 것입니다)

🅴 ㄷ 불규칙 (ㄷ Irregular)

받침 'ㄷ'이 모음 앞에서 'ㄹ'로 바뀌고 '을 것입니다 / 을 것입니까'가 붙습니다.

'ㄷ' batchim changes to 'ㄹ' before a vowel, then takes '을 것입니다 / 을 것입니까'.

ㄷ → ㄹ + 을 것 받침 'ㄷ'이 'ㄹ'로 바뀌고 '을 것입니다'가 결합됩니다 'ㄷ' batchim changes to 'ㄹ', then '을 것입니다' attaches

🅵 ㅂ 불규칙 (ㅂ Irregular)

받침 'ㅂ'이 모음 앞에서 '우'로 바뀌고, '우 + 을'은 '울'로 줄어듭니다 → ~울 것입니다 / 울 것입니까

'ㅂ' batchim turns into '우' before a vowel; '우 + 을' contracts to '울' → ~울 것입니다 / 울 것입니까

ㅂ → 우 + 을 → 울 것 받침 'ㅂ'이 '우'로 바뀌고 '을'과 줄어 '울'이 됩니다 'ㅂ' becomes '우' and contracts with '을' to form '울'
