Predicate Grammar 16

Guess / Supposition

서술어 문법 16: 추측

~것 같다 (It seems / I think)

Grammar Overview · 문법 정리

1

Why so many "guess" expressions?
왜 한국어에는 추측 표현이 많을까요?

한국어에는 단정을 피하고 부드럽게 말하는 간접·완곡 표현 문화가 발달해 있습니다. 오랜 역사의 불확실한 시대를 거치며 이런 표현을 선호하게 되었다고 보기도 합니다.
Korean has a rich culture of indirect, softened expression that avoids sounding too assertive. Some attribute this to the uncertain times in Korea's long history, which may have led people to prefer softer, more indirect ways of speaking.
English: "The movie will be fun."
(direct, assertive)
Korean: "그 영화는 재미있을 것 같습니다."
(indirect, guess — even if you're sure!)
2

Present · Past · Future guess
현재 · 과거 · 미래 추측

행동이 일어난 시점에 맞는 관형사형 어미(~ㄴ/은, ~는, ~ㄹ/을)를 선택합니다.
Choose the modifier that matches when the action happened.

Verb (동사) — three tenses

Tense
시제		Pattern
패턴		Example (비가 오다 = rain)
Past
(과거)		~ㄴ/은 것 같다비가 온 것 같습니다
(seems like it rained)
Present
(현재)		~는 것 같다비가 오는 것 같습니다
(seems like it's raining)
Future
(미래)		~ㄹ/을 것 같다비가 올 것 같습니다
(seems like it will rain)

Adjective (형용사) — three tenses

Tense
시제		Pattern
패턴		Example (비싸다 = expensive)
Past
(과거)		~았/었던 것 같다비쌌던 것 같습니다
(seems it was expensive)
Present
(현재)		~ㄴ/은 것 같다비싼 것 같습니다
(seems expensive)
Future
(미래)		~ㄹ/을 것 같다비쌀 것 같습니다
(seems it will be expensive)
💡 형용사 과거 주의 — 형용사 과거 추측은 동사와 달리 ~ㄴ/은이 아니라 ~았/었던을 씁니다 (비싼 것 같다 = 현재 / 비쌌던 것 같다 = 과거).
For adjectives the past guess uses ~았/었던, not ~ㄴ/은 (which stays present).

Explanation

📝 어젯밤에 ㅅ이 들어가는 이유 · 사이시옷

두 명사가 합쳐져 합성어가 될 때, 한국어는 그 사이에 ㅅ을 넣을 때가 있습니다. 이 ㅅ은 뒤 단어의 첫소리가 된소리(강한 소리)로 나거나(어젯밤·빗길) ㄴ 소리가 덧남(콧물·나뭇잎)을 표시합니다.
When two nouns combine into a compound word, Korean sometimes inserts an extra ㅅ between them. This ㅅ signals that the second word's first sound either becomes a tense (reinforced) consonant (어젯밤, 빗길) or gains an added ㄴ sound (콧물, 나뭇잎).

어제 + 밤 → 어젯밤 — last night
나무 + 잎 → 나뭇잎 — tree leaf
비 + 길 → 빗길 — rainy road
코 + 물 → 콧물 — runny nose

216) I think this exam will be difficult.

어휘Vocabulary
이번this time 시험exam 어렵다to be difficult
이번 시험이 어려울 것 같습니다.
한국어 어순: 주어 + 서술어(추측)
Korean order: Subject + Predicate(Guess)
영어
English		역할
Role		한국어
Korean		해설
Explanation
this exam주어
Subject		이번 시험이이번 시험 + 이
I think will be difficult서술어(추측)
Predicate (Guess)		어려울 것 같습니다어렵다 → 어렵 + 을 것 같다 → 어려우 + ㄹ 것 같다 → 어려울 것 같습니다
📝 어렵다 — ㅂ 불규칙 활용 (ㅂ-irregular derivation)
어렵 + 을 것 같다 → 어려우 + ㄹ 것 같다 → 어려울 것 같다 → 어려울 것 같습니다
① ㅂ → 우: 딱딱한 발음인 받침 ㅂ이 부드러운 발음인 모음을 만나면, 부드러운 발음인 우/오로 바뀝니다 (앞 모음 ㅕ가 우를 선택).
② 어간이 모음으로 끝나므로 미래 수식어 ㄹ 것 같다가 붙습니다 (받침 없음).
① ㅂ → 우: The hard consonant ㅂ at the stem end softens into a vowel — 우/오 — when it meets a vowel ending; here ㅕ selects 우.
② Stem now ends in a vowel, so the future modifier ㄹ 것 같다 is used (no 받침).
