📝 형용사로 관형어 만들기Making adjective modifiers

형용사로 명사를 꾸밀 때는 형용사 어간에 ㄴ / 은을 붙입니다. 어간에 받침이 없으면 ㄴ, 받침이 있으면 은을 씁니다.
To modify a noun with an adjective, attach ㄴ / 은 to the adjective stem — ㄴ if the stem has no final consonant, 은 if it does.

친절하다 + 남자 → 친절한 남자
(a kind man)
예쁘다 + 꽃 → 예쁜 꽃
(a pretty flower)
작다 + 방 → 작은 방
(a small room)
좋다 + 사람 → 좋은 사람
(a good person)

💡 형용사 어간 받침 유무에 따른 ㄴ / 은 규칙과 동사·시제 관형어는 관형어 단원(474~488)에서 자세히 배웁니다.
The full ㄴ / 은 rules and verb/tense modifiers are covered in detail in the dedicated 관형어 (modifier) unit.
