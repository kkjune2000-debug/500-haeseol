Predicate Grammar 12

Experience

서술어 문법 12: 경험

~ㄴ/은 적이 있다/없다, ~아/어 보다

Grammar Overview · 문법 정리

1

Two ways to talk about experience
경험을 표현하는 두 가지 패턴

PatternMeaningExample
~ㄴ/은 적이 있다/없다have / have never done (experience exists)간 적이 있습니다
(I have been there)
~아/어 보다try doing / have tried가 보았습니다
(I have tried going)
2

Formation
~ㄴ/은 적이 있다 만드는 법

No 받침: Verb + ㄴ 적이 있다  |  With 받침: Verb + 은 적이 있다가다 → 간 적이 있다 · 먹다 → 먹은 적이 있다
동사
Verb		 받침
Batchim		 경험 표현
~ㄴ/은 적이 있습니다		 뜻
Meaning
가다
go		 X
없음 none		 가 + ㄴ → 간 적이 있습니다 have been
보다
see		 X
없음 none		 보 + ㄴ → 본 적이 있습니다 have seen
먹다
eat		 O
있음 yes		 먹 + 은 → 먹은 적이 있습니다 have eaten
읽다
read		 O
있음 yes		 읽 + 은 → 읽은 적이 있습니다 have read

💡 부정형은 있습니다 대신 없습니다를 씁니다.
For the negative, replace 있습니다 with 없습니다 — 간 적이 없습니다 (have never been).

3

Formation
~아/어 보다 만드는 법

동사의 마지막 모음에 따라 아/어가 결정됩니다. 보조동사 보다 = 시도하다.
Vowel rule (verb's last vowel decides 아/어). The auxiliary verb 보다 (lit. see) = try.
Verb + 아/어 보다ㅏ·ㅗ → 아 보다  |  그 외 모음 → 어 보다
Bright vowel (ㅏ·ㅗ) → 아 보다 | other vowels → 어 보다
동사
Verb		 끝 모음
Last vowel		 시도 표현
~아/어 보다		 뜻
Meaning
가다
go		 ㅏ
양성 bright		 가 + 아 → 가 보다 try going
받다
receive		 ㅏ
양성 bright		 받 + 아 → 받아 보다 try receiving
먹다
eat		 ㅓ
음성 dark		 먹 + 어 → 먹어 보다 try eating
하다
do		 하다
불규칙 special		 하 + 여 → 해 보다 try doing

💡 보조동사 보다를 바꿔 다양하게 활용합니다: 보았습니다(과거) · 보세요(권유) · 보지 못했습니다(부정).
Change the auxiliary 보다: 보았습니다 (past) · 보세요 (please try) · 보지 못했습니다 (haven't been able to try).

4

Compare the two patterns
두 패턴 비교

둘 다 경험이지만 뉘앙스가 다릅니다.
Both express experience, but the nuance differs.
📝 언제 사용하나 · When to use each pattern
Pattern When to use Example
~ㄴ/은 적이 있다Remote past
(no specific recent date)		✓ 한국에 간 적이 있습니다
❌ 지난 주에 간 적이 있습니다
~아/어 보다Recent past
(specific recent date)		✓ 지난 주에 가 보았습니다
⚠️ '~ㄴ/은 적이 있다'는 가까운 과거에 사용하지 않습니다
'~ㄴ/은 적이 있다'는 가까운 과거(어제·지난 주 등)에는 사용하지 않습니다.
'~ㄴ/은 적이 있다' — not used for recent past (yesterday, last week, etc.).

❌ 지난 주에 간 적이 있습니다
✅ 지난 주에 가 보았습니다
✅ (예전에) 한국에 간 적이 있습니다
