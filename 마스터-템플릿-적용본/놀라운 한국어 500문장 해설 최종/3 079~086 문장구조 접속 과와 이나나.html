문장 만들기

Sentence Building

79) I go to the Korean language school on Monday and Wednesday.

어휘Vocabulary
월요일Monday 수요일Wednesday 한국어 학원Korean language school 가다go
저는 월요일과 수요일에 한국어 학원에 갑니다.
한국어 어순: 주어 + 부사어(시간 + 장소) + 서술어(동사)
Korean order: Subject + Adverbial(Time + Place) + Predicate(Verb)
  1. 저는 월요일과 수요일에 한국어 학원에 갑니다.I go to the Korean language school on Monday and Wednesday.
만들기Word building저 + 는월요일과 수요일 + 에한국어 학원 + 에가다 → 가 + ㅂ니다 → 갑니다

80) I bought fruits, vegetables, and fish at the market yesterday.

어휘Vocabulary
시장market 과일fruit 야채vegetables 생선fish
저는 어제 시장에서 과일과 야채와 생선을 샀습니다.
한국어 어순: 주어 + 부사어(시간 + 장소) + 목적어 + 서술어(동사)
Korean order: Subject + Adverbial(Time + Place) + Object + Predicate(Verb)
  1. 주어 + 목적어 + 서술어(동사)Subject + Object + Predicate (Verb)저는 과일과 야채와 생선을 샀습니다.I bought fruits, vegetables, and fish.
  2. 주어 + 부사어(장소) + 목적어 + 서술어(동사)Subject + Adverbial (Place) + Object + Predicate (Verb)저는 시장에서 과일과 야채와 생선을 샀습니다.I bought fruits, vegetables, and fish at the market.
  3. 주어 + 부사어(시간) + 부사어(장소) + 목적어 + 서술어(동사)Subject + Adverbial (Time) + Adverbial (Place) + Object + Predicate (Verb)저는 어제 시장에서 과일과 야채와 생선을 샀습니다.I bought fruits, vegetables, and fish at the market yesterday.
만들기Word building저 + 는어제시장 + 에서과일과 야채와 생선 + 을사다 → 사 + 았습니다 → 샀습니다

81) I eat bread or rice in the morning.

어휘Vocabulary
아침morning 빵bread 밥rice 먹다eat
저는 아침에 빵이나 밥을 먹습니다.
한국어 어순: 주어 + 부사어(시간) + 목적어 + 서술어(동사)
Korean order: Subject + Adverbial(Time) + Object + Predicate(Verb)
  1. 주어 + 목적어 + 서술어(동사)Subject + Object + Predicate (Verb)저는 빵이나 밥을 먹습니다.I eat bread or rice.
  2. 주어 + 부사어(시간) + 목적어 + 서술어(동사)Subject + Adverbial (Time) + Object + Predicate (Verb)저는 아침에 빵이나 밥을 먹습니다.I eat bread or rice in the morning.
만들기Word building저 + 는아침 + 에빵이나 밥 + 을먹다 → 먹 + 습니다 → 먹습니다

82) I watch movies or dramas at home on weekends.

어휘Vocabulary
주말weekend 집home, house 영화movie 드라마dramas 보다watch, see
저는 주말에 집에서 영화나 드라마를 봅니다.
한국어 어순: 주어 + 부사어(시간 + 장소) + 목적어 + 서술어(동사)
Korean order: Subject + Adverbial(Time + Place) + Object + Predicate(Verb)
  1. 주어 + 목적어 + 서술어(동사)Subject + Object + Predicate (Verb)저는 영화나 드라마를 봅니다.I watch movies or dramas.
  2. 주어 + 부사어(장소) + 목적어 + 서술어(동사)Subject + Adverbial (Place) + Object + Predicate (Verb)저는 집에서 영화나 드라마를 봅니다.I watch movies or dramas at home.
  3. 주어 + 부사어(시간) + 부사어(장소) + 목적어 + 서술어(동사)Subject + Adverbial (Time) + Adverbial (Place) + Object + Predicate (Verb)저는 주말에 집에서 영화나 드라마를 봅니다.I watch movies or dramas at home on weekends.
만들기Word building저 + 는주말 + 에집 + 에서영화나 드라마 + 를보다 → 보 + ㅂ니다 → 봅니다

83) She is pretty and smart.

어휘Vocabulary
그녀she 예쁘다to be pretty 똑똑하다to be smart
그녀는 예쁘고 똑똑합니다.
한국어 어순: 주어 + 서술어
Korean order: Subject + Predicate
  1. 그녀는 예쁘고 똑똑합니다.She is pretty and smart.
만들기Word building그녀 + 는예쁘다 + 똑똑하다 → 예쁘고 똑똑하다 → 예쁘고 똑똑합니다

84) Today it is cold, the wind is blowing, and it is raining.

어휘Vocabulary
오늘today 춥다to be cold 바람wind 불다blow 비가 오다rain
오늘은 춥고 바람이 불고 비가 옵니다.
한국어 어순: 주어 + 서술어 1 + 서술어 2 + 서술어 3
Korean order: Subject + Predicate 1 + Predicate 2 + Predicate 3
  1. 오늘은 춥고 바람이 불고 비가 옵니다.Today it is cold, the wind is blowing, and it is raining.
만들기Word building오늘 + 은춥다 → 춥 + 고 → 춥고바람이 불다 → 바람이 불 + 고 → 바람이 불고비가 오다 → 비가 오 + ㅂ니다 → 비가 옵니다

85) I meet friends or exercise on weekends.

어휘Vocabulary
친구friend 만나다meet 운동을 하다exercise
저는 주말에 친구를 만나거나 운동을 합니다.
한국어 어순: 주어 + 부사어(시간) + 서술어 1 + 서술어 2
Korean order: Subject + Adverbial(Time) + Predicate 1 + Predicate 2
  1. 주어 + 서술어 1 + 서술어 2Subject + Predicate 1 + Predicate 2저는 친구를 만나거나 운동을 합니다.I meet friends or exercise.
  2. 주어 + 부사어(시간) + 서술어 1 + 서술어 2Subject + Adverbial (Time) + Predicate 1 + Predicate 2저는 주말에 친구를 만나거나 운동을 합니다.I meet friends or exercise on weekends.
만들기Word building저 + 는주말 + 에친구를 만나다 → 친구를 만나 + 거나 → 친구를 만나거나운동을 하다 → 운동을 하 + ㅂ니다 → 운동을 합니다

86) Kimchi is spicy but delicious.

어휘Vocabulary
김치kimchi 맵다to be spicy 맛있다to be delicious
김치는 맵지만 맛있습니다.
한국어 어순: 주어 + 서술어
Korean order: Subject + Predicate
  1. 김치는 맵지만 맛있습니다.Kimchi is spicy but delicious.
만들기Word building김치 + 는맵다 + 맛있다 → 맵지만 맛있다 → 맵지만 맛있습니다
