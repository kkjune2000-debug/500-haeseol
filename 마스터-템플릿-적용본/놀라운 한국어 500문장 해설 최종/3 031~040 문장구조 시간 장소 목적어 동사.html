문장구조 4

주어 + 시간 + 장소 + 목적어 + 서술어

Sentence Structure 4

Subject + Time + Place + Object + Verb

New Grammar · 새로운 문법

1
한국어에서 가장 많이 사용되는 문장 구조는 다음과 같습니다.
The most common Korean sentence structure is:
Subject + Object + Predicate주어 + 목적어 + 서술어
부사어란? 시간, 장소, 목적, 이유, 조건 등 동작이 일어나는 배경 정보를 더하는 말입니다. 한국어에서 부사어는 보통 주어 다음에 옵니다.
What is an adverbial (부사어)? A word that adds background information about an action — time, place, purpose, reason, condition, and so on. In Korean, an adverbial usually comes right after the subject.
Subject + Adverbial + (Object) + Predicate주어 + 부사어 + (목적어) + 서술어 — 일반적 위치는 주어 다음입니다. 목적어를 ( )로 묶은 것은 모든 문장에 목적어가 오는 것은 아니기 때문입니다.
The usual spot is right after the subject. The Object is in ( ) because not every sentence has one.
Adverbial + Subject + (Object) + Predicate부사어 + 주어 + (목적어) + 서술어 — 부사어를 강조하고 싶을 때는 주어 앞에 올 수도 있습니다.
To emphasize the adverbial, it can also come before the subject.
2
부사어는 문장에 하나씩 더해 가며 '언제·어디서·왜'를 점점 더 자세하게 만들어 줍니다. 아래에서 한 단계씩 쌓아 가며 살펴봅시다.
Adverbials are added one at a time, making "when / where / why" progressively clearer. Let's build a sentence up step by step below.

Key: Time, Place, Purpose, Reason, Condition — all of these adding words are adverbials. They normally sit right after the subject.
3
초급에서 가장 많이 사용되는 부사어는 시간과 장소입니다.
In beginner Korean, the most common adverbials are time and place.
Subject + Adverbial(Time + Place) + Object + Predicate주어 + 부사어(시간 + 장소) + 목적어 + 서술어
4

Time — Noun + 에
시간 — 명사 + 에

시간을 나타내는 명사에 에를 붙입니다.
Attach 에 to a time noun.
예Examples 아침에, 점심에, 저녁에, 1시에
⚠️ 예외 (Exceptions) — 에 없이 단독으로 쓰는 시간 단어 (Time words used alone, without 에)

Attach 에서 to a place noun.
예Examples 학교에서, 집에서, 운동장에서, 백화점에서

Key: 에 = destination / direction (where the movement is heading). 에서 = where an action takes place.

📅 시간 명사 with no 에Time nouns that take no particle

대부분의 시간 표현에는 시간 조사 '에'를 붙입니다 (예: 월요일에, 아침에, 7시에). 하지만 다음 시간 명사들은 조사 없이 그대로 씁니다:
Most time expressions attach the time marker '에' (e.g. 월요일에, 아침에, 7시에). But these common time nouns are used directly, with no particle:

어제 — yesterday
오늘 — today
내일 — tomorrow
모레 — the day after tomorrow
그저께 — the day before yesterday
지금 — now
매일 — every day
언제 — when (interrogative)
