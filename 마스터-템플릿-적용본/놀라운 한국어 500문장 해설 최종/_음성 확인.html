남성 음성이 없을 때If there is no male voice

  1. 가장 빠른 길 — Microsoft Edge 로 열기. 이 파일을 마우스 오른쪽 단추로 누르고 「연결 프로그램 → Microsoft Edge」를 고르십시오. Edge 는 인터넷에 연결되어 있으면 Microsoft InJoon Online (Natural) 남성 음성을 씁니다. Fastest: open this file in Microsoft Edge. When online, Edge offers the natural male voice InJoon.
  2. 인터넷 없이 쓰려면 — 윈도우에 음성 추가. 설정 → 시간 및 언어 → 음성 → 음성 관리 → 음성 추가 → 한국어를 고르십시오. 내레이터의 자연스러운 음성 추가에서도 한국어 음성을 받을 수 있습니다. 받은 뒤에는 모든 브라우저에서 나옵니다. To work offline, add Korean voices in Windows Settings → Time & language → Speech → Manage voices, or add natural voices under Narrator.
  3. 그래도 없으면. 해설집의 「남」 단추는 여성 음성을 낮춰 읽습니다. 진짜 남성 음성이 아니라는 안내가 함께 뜹니다. Otherwise the 남 button in the workbook reads with the female voice pitched down, and says so.
