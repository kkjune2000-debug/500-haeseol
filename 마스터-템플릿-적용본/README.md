# 놀라운 한국어 500 해설집 (Amazing Korean 500 — Annotated Edition)

A bilingual (Korean / English) study collection of 500 Korean sentences, organized by grammar topic. Each sentence is presented with:

- A writing-practice prompt
- A morphological breakdown table (어순 · 역할 · 형태 · 해설)
- Vocabulary toggles, listen buttons, and matching games

## Structure

The HTML files are grouped by sentence number ranges and grammar category:

| Range | Category |
|---|---|
| 1 – 86 | 문장구조 (Sentence structure) |
| 87 – 247 | 서술어 문법 (Predicate grammar) |
| 248 – 365 | 부사어 문법 (Adverbial grammar) |
| 366 – 500 | 기타 문법 (Other grammar — irregulars, particles, comparatives, honorifics, etc.) |

Open any `*.html` file directly in a browser. Each lesson is self-contained.

## Grammar Summary Style

Each lesson's **문법 정리** (Grammar Overview) section follows a uniform 4–5 step layout:

1. **Pattern box** — the bare formula (e.g., `Verb stem + 려면 + . + 아/어야 하다`).
2. **Conjugation table** — yellow-themed table with 받침 없음/있음 labels and 6 representative verbs.
3. **Common usage table** — categorized by domain (학교·직장, 일상, 인생 시기, etc.).
4. **Comparison** *(optional)* — vs related forms (전에 vs 후에, ~고 vs ~아/어서, etc.).
5. **Word order** — `주어 + 부사어(...) + 목적어 + 서술어(동사)` plus 격식체 example sentences.

All explanations pair Korean text with English on the next line. Examples use 격식체 (`-ㅂ니다/습니다`).
