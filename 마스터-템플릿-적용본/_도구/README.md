### 다국어 검사가 왜 생겼는가 — 2026-08-18

- **`check_i18n.py` ①** 표 머리 3,344개 가운데 영어가 먼저인 것이 **69곳**이었습니다. 「Korean order: …」 11곳을 「영어 문장이라 오탐」이라 판단했다가, 세어 보니 같은 제목 행이 **489개는 한국어 먼저·11개만 영어 먼저**여서 진짜 결함이었습니다. **짐작하지 말고 세십시오.**
- **`check_i18n.py` ②** 번역 슬롯이 괄호를 반으로 물던 곳 **34곳**. `<span lang="en">Present (~</span>게 되다)` 를 일본어로 찍으면 「現在 (~」 뒤에 `게 되다)` 가 남습니다. ★ 처음 잣대(「슬롯 안에서 짝이 안 맞으면」)로는 **564곳**이 나왔는데 대부분 문장 번호 `489)` 였습니다. **모자란 짝이 슬롯 바로 밖에 있을 때만** 세야 합니다.
- **`check_wordbreak.py`** 390px에서 **2,530곳**이 낱글자로 갈리고 있었습니다. ★ 세로쓰기(`writing-mode: vertical-rl`)는 오탐입니다 — 폭을 390·794·900·1200으로 바꿔도 개수가 같으면 폭 문제가 아닙니다.
- **`check_koen_line.py`** 「한국어 한 줄, 영어 한 줄」(2026-08-18 사용자 지시)을 지키는지 봅니다. ★★**소스를 읽어 세지 말 것 — 그물이 양쪽으로 다 틀렸습니다.** 「한국어…`<span lang=en>`영어」로 찾으니 **84줄**이 나왔는데 그 span 이 `display:block` 이면 이미 줄이 갈려 있어 대부분 헛것이었고(`.ci-rule-desc .en`·`.cx-ex em`·`_음성 확인`의 `.en`), 거꾸로 문장 끝(`니다.`)으로만 찾으니 15파일에서 inline 인 `.cr-en` 을 1줄만 잡았습니다. 브라우저에 그려 재니 **390px 0곳 · 1280px 5곳**이었습니다.

### 이 검사들이 왜 생겼는가 — 실제로 터졌던 사고

- **`check_script_order.py`** — `jmSpk`를 정의한 `<script>`를 표를 그리는 스크립트 **뒤에** 넣었습니다. `ReferenceError`가 나면서 「퀴즈 2 · 쓰기」 표가 **23개 파일에서 통째로 사라졌습니다.** 같은 블록 안이면 호이스팅으로 살지만 블록이 다르면 죽습니다. `onclick="…"` 안에서 부르는 것은 클릭할 때 실행되므로 괜찮습니다.
- **`check_style.py`** — 스크립트를 꽂을 자리를 정규식 `<body[^>]*>`로 찾았더니 **CSS 주석 안의 글자 `3) <body>`** 에 걸려 `<style>` 한복판에 스크립트를 넣었습니다. 스크립트의 `/* … */` 가 바깥 CSS 주석을 먼저 닫아 그 뒤 CSS가 통째로 죽었고 `.container{max-width:800px}` 도 함께 죽어 **조사 A~F가 화면 가득 퍼졌습니다.** 그때 저는 "CSS 글자가 있으니 같다"고 잘못 답했습니다. → **태그가 아니라 적용되는가를 보십시오.**
- **`check_structure.py`의 `data-ans` 대조** — 설명만 고치는 작업에서 정답이 바뀌면 그건 사고입니다. HEAD와 대조해 즉시 잡습니다.
  ★ **HEAD와 대조하므로 커밋을 미루면 이 그물이 무뎌집니다.** 2026-08-10에 사흘치가 미커밋으로 쌓여 23파일이 걸려 있었는데, 값을 하나하나 대조해 보니 전부 의도한 변경이었습니다. 일이 끝나면 커밋하십시오.

### `check_spec.py` 의 예외표 — 바깥 상자 이름이 갈래마다 다릅니다

폭을 재려면 바깥 상자를 찾아야 하는데 그 이름이 하나가 아닙니다. 본문 103개는 `.container` 800px 이지만 셋은 다릅니다.

| 파일 | 바깥 상자 | 폭 | 왜 |
|---|---|---|---|
| `4 부록 2 부정법.html` | `.page-container` | 210mm | A4 인쇄 낱장 (종이로 뽑는 표) — ★**그대로 두기로 한 것입니다(2026-08-10 사용자 결정).** 소리가 없고 배경이 `#555` 인 것도 알고 있는 상태입니다★ |
| `4 부록 8 기초문법총정리.html` | `.sheet` | 1380px | 일부러 넓은 문법 맵 |
| `_음성 확인.html` | `.wrap` | 860px | 브라우저 음성 진단용 (본문 아님) |

셋 다 `margin:0 auto` 로 **가운데 정렬돼 있어 화면 가득 퍼지지 않습니다.** 옛 검사기는 `.container` 라는 이름만 찾아 "폭=- · 화면 가득 퍼집니다"라고 **잘못 알렸고**, 인수인계 문서에도 그대로 옮겨 적혀 있었습니다(2026-08-10 바로잡음).

예외는 스크립트 맨 위 `EXCEPT` 에 **폭까지 함께** 적어 둡니다. 이름만 눈감아 주면 그 파일들은 영영 안 보게 되므로, **폭이 바뀌면 예외 쪽에서 잡히게** 해 두었습니다. 새 갈래의 페이지를 만들면 여기 한 줄 더하십시오.

★ 폭을 재는 자리는 **맨 처음 선언**입니다. `@media print` 안에서 같은 이름이 `width:100%` 로 다시 선언되므로(부록 2), 뒤엣것을 쓰면 인쇄용 값을 화면 폭으로 잘못 읽습니다.

## 음원

| 파일 | 쓰임 |
|---|---|
| `audio_build.py list` | 소리 단추가 부르는데 음원이 없는 문장을 **보기만** |

```powershell
pip install edge-tts        # 무료, 열쇠(API key) 필요 없음
python audio_build.py list
python audio_build.py make
python audio_build.py wire
python check_structure.py   # 번호표가 가리키는 파일이 없는 것 0개인지
```

목소리는 **여성 `ko-KR-SunHiNeural` · 남성 `ko-KR-HyunsuMultilingualNeural`** 로 고정입니다(사용자가 들어 보고 고른 것). Hyunsu는 다국어 음성이라 한국어·일본어·영어·중국어를 **한 사람 목소리로** 읽습니다 — 다른 언어판을 만들 때 화자를 바꾸지 않아도 됩니다.

### 소리 구조

```
_소리\f\0001.mp3   여성          _소리\m\0001.mp3   남성
_소리\*.json       문장 → 번호   ← 번호가 겹치지 않게 하려는 장부일 뿐
각 HTML 안의  var AK_SND = {…}   ← 브라우저가 실제로 보는 번호표
```

★ **브라우저가 보는 것은 HTML 안의 `AK_SND` 입니다.** json만 고치면 아무 일도 일어나지 않습니다. 반드시 `wire` 를 돌리십시오.

재생은 `speakKorean(문장, 성별)` → 구운 mp3(`akPlayFile`) → 없으면 브라우저 음성(`akSpeakTTS`) 순입니다.
`speechSynthesis.cancel()` 직후 바로 `speak()` 하면 **목소리가 바뀝니다.** 60ms 기다리는 `setTimeout` 을 지우지 마십시오.

## 새 도구를 쓸 때

- 출력은 `_paths.stdout()` 을 쓰십시오. PowerShell 기본 코드페이지(cp949)에서 한글이 깨집니다.
- 파일은 **반드시 `--apply` 를 따로 두고** 먼저 모의 실행(dry run)하십시오. 바꿀 개수가 예상과 맞을 때만 반영합니다.
- 쓰기 직전에 **태그 짝 검사**를 넣고, 깨지면 그 파일은 건너뛰게 하십시오. 한 번에 여러 파일을 망가뜨리는 것을 막습니다.
- 여러 자리를 고칠 때는 **뒤에서 앞으로** 고치십시오. 앞부터 고치면 뒤쪽 위치가 밀립니다. 정렬은 반드시 **위치 기준**으로 — 한 번은 파일 이름 문자열로 정렬해 17개 파일의 태그를 깨뜨린 적이 있습니다.
