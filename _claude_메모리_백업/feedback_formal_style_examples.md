**Korean example sentences MUST use 격식체 (formal style — `-ㅂ니다/습니다` endings).**

**Why:** The user explicitly instructed this on 2026-05-28 while reviewing the 어간 현재형 grammar summary — informal polite endings (`-아요/-어요/-여요`) had to be converted to formal `-ㅂ니다/습니다`. The textbook is at a level/register that consistently teaches the formal polite ending; example sentences must match.

**How to apply:**
- Sentence-final verbs in 예문 (example sentences) must end in `-ㅂ니다` (vowel stem) or `-습니다` (consonant stem) for statements.
- Convert: `갔어요 → 갔습니다`, `해요 → 합니다`, `노력해요 → 노력합니다`, `씁니다`, `가고 싶어요 → 가고 싶습니다`, `양치해요 → 양치합니다`.
- For questions: `-ㅂ니까?/-습니까?` (e.g., `갑니까?`, `먹습니까?`).
- **Exception:** `~세요 / ~으세요` forms (polite imperative — already at the correct register, e.g., `가지 마세요`, `조심하세요`). Leave these unchanged.
- Other exception cases that may appear naturally formal/established and don't need rewriting: dictionary citation forms (`-다`), grammar pattern labels (`~고 싶다`), idiomatic phrases.
- Applies to: 예문 in gstep blocks, explain-notes, callout tables, blockquotes. Anywhere a complete sample sentence is shown to illustrate a grammar point.
