**대본(transcript) 텍스트층** (2026-07-25 조사): 텍스트 추출 가능 = 35·36·37·41·47·52·60·**83**(통합 PDF지만 텍스트) / 이미지(렌더·OCR) = **64·91·96·102**. ★읽기와 다르다 — 듣기는 83도 텍스트, 64는 이미지★. 정답 PDF·문제 PDF 12회차 모두 있음(대개 듣기+쓰기 합본).

**유형 구조(35회 기준)**: [1~3] 알맞은 그림·그래프 / [4~8] 이어질 수 있는 말 / [9~12] 이어서 할 행동 / [13~16] 내용 일치 / [17~20] 중심 생각 / [21~50] 한 담화 두 물음(짝, 담화별: 21~36 대화·담화, 37~38 교양프로그램, 39~40·47~48 대담, 41~42·45~46·49~50 강연, 43~44 다큐멘터리) / [51~54] 쓰기.

**확립된 제작 방식(TOPIK1 듣기에서 그대로 옮긴다)** — TOPIK1은 유형별 듣기 해설이 완성돼 있다(`토픽1 듣기 해설/`). 방식: 유형 HTML **곁에 「소리」 폴더**를 두고 문항별 mp3를 `35회 01.mp3`·`35회 00 보기.mp3`로 담아 `audio:'유형01 소리/35회 01.mp3'` 상대경로로 참조(encodeURI+new Audio). **자족 HTML 아님 — 소리 폴더가 함께 다닌다**(base64 임베드는 용량상 불가). 빌드 3종: `raw_dNN`(판독본)+`dNN_content`(해설)+`build_dNN`(템플릿 자리표 채움)+`audio_map.json`(문항→mp3 경로). ★함정: 따옴표 없는 한글 키(공백 든)는 JS를 통째로 죽인다(구문오류라 window.onerror도 못 잡음)★. 검사: `probe_dNN.py`·`check_selfcontained.py`.

- **★일반화 짝 모듈(유형07~20 재사용) — 유형번호만 바꿔 돌린다★**: `t2l_pairlib.py`(설정 PAIR_A·PAIR_TITLE, region/render_img, **badge(ask)로 배지 계산**, **clean_ns=공백+PUA(사설영역 U+E000~F8FF)+제어문자 제거**), `t2l_pair_rawprep.py TP`→ 워크플로 `wf/pair_raw.js`(args=TP)→ `t2l_pair_rawasm.py TP <task>`(글자대조·setask 정리) / `t2l_pair_contentprep.py TP`→ `wf/pair_content.js`(args=TP)→ `t2l_pair_contentasm.py TP <task>`(ok=정답·**껍데기 길이검사·키릴검사**) / `t2l_pair_build.py TP`(담화1+물음2 새 구조, ok·껍데기 assert) / `t2l_pair_reviewfiles.py TP`→ `wf/pair_review.js`(args=TP). 음원은 `t2l_audiolib.extract_pair`(짝별 배치추출은 루프). 06은 전용 스크립트(구조 동일, q21/q22 키).

**듣기 유형 제작 파이프라인(유형02+ 재사용)**:
1. `t2l_dump13`/렌더로 대본 판독 → `t2l_rawNN.py`(RAW=화자·대사, ANS, KIND). 텍스트 회차 get_text, 이미지 회차(64·91·96·102) 통합PDF 렌더 눈판독(그림도 함께 보임). ★대본 띄어쓰기는 렌더 눈판독으로 확정★.
2. 정답 — 텍스트 정답표 파싱(문항·정답·배점 2열), 이미지 정답표는 렌더 눈판독.
3. 그림 크롭 `t2l_imgNN.py` — 임베디드 이미지 rect 를 세로조각 잇고 2×2 로. **64는 통짜 페이지스캔이라 통합형식 고정좌표**(91/96/102 위치가 템플릿).
4. 음원 `t2l_audioNN.py` — 위 정렬로 문항별 mp3 복사(통짜 36·37은 `_split` 로 답시간 무음 경계 컷).
5. 합성판(scratchpad/comp_H.png, 3×4) → **회차별 병렬 워크플로**(agentType general-purpose, 각 에이전트가 합성판 Read + 대본/정답으로 해설 JSON 작성, 스키마: q1/q2/q3 = {lineEn, sol, solEn, clue[[..]], pics[4]{d,dEn,ok,why,whyEn}, vocab[[..]]}).
6. `t2l_contentNN_assemble`(result.rounds 추출 → json, ok=정답 검사) → `t2l_contentNN.py`(json 로드) → `t2l_buildNN.py`(TOPIK1 build_d1516 본뜸: 음원 플레이어+2×2 그림클릭+대본 게이팅). ★build 가 ok=정답·그림존재 assert★. ★why/sol 은 esc — 워크플로 평문에 `>` 비교기호가 있어 raw 삽입 시 태그로 먹힘★.
7. Ultracode 적대 검증(회차별, 합성판 대조로 그림묘사·영어·성별·문체) → 확인분 `_fix.py` 로 json 수정 → 재빌드.
