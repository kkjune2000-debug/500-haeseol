인수인계 문서에 적을 때 **확인한 것과 확인하지 않은 것을 갈라 적는다.**

**Why:** 「듣기 5~6번 지시문 = 이어지는 말을 고르십시오」라고 훑어본 기억으로 적었는데, 기계로 확인하니 **35회만 「다음 말에 이어지는 것을」로 달랐다**. 유형01 지시문은 12회차가 다 같아서 유형02도 그럴 것이라 짐작한 것이다. 다음 사람은 이 문서를 믿고 그대로 쓴다.

**How to apply:**
- 「기계 확인함(텍스트 7회차)」 / 「눈으로 훑은 것이라 확정 아님 — 만들 때 다시 볼 것」처럼 **출처와 확실성을 함께** 적는다.
- 이미지 PDF 회차는 기계 그물이 없다는 것을 문서에 명시한다.
- 코드 예시는 **heredoc 으로 넣지 말 것** — 백슬래시가 먹혀 `\b` 가 백스페이스 문자(0x08)로 박힌 적이 있다. Write 로 만들고, 넣은 뒤 **되읽어 확인**한다.
- 같은 교훈: 틀이 같아 보여도 짐작하지 말고 렌더러·PDF 를 직접 본다. [[haeseol-yuhyeong-copy]]
