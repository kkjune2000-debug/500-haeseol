`마스터-템플릿-적용본\` 전체 HTML을 **그룹번호 접두사 + 공백 통일** 형식으로 일괄 변경(2026-06-16, 106개). 정렬 순서 = **시제 → 조사 → 1~500 본문 → 부록**.

규칙:
- **1 시제 …** — 예 `1 시제 0 시제란무엇인가`, `1 시제 1 현재형 A 받침없음`, `1 시제 2 과거형 A 규칙`, `1 시제 종합 시험` (21개)
- **2 조사 …** — 예 `2 조사 0 조사란무엇인가`, `2 조사 A 은는 이가`, `2 조사 전체 시험` (9개)
- **3 ###~### …** — 500문장 본문, 시작·끝 번호 **3자리 0채움**. 예 `3 001~010 문장구조 주어 형용사`, `3 123~141 서술어 문법 부정`, `3 489~500 기타 문법 존댓말` (67개)
- **4 부록 N …** — 예 `4 부록 1 숫자`, `4 부록 2 부정법`, `4 부록 3 격식체 구어체 문어체`, `4 부록 4~7 기초문법연습 01~04`, `4 부록 8 기초문법총정리` (8개)
- 옛 통합본은 `_부록 총정리(구버전).html`로 분리.

**통합본 재빌드 보류(2026-06-16):** `임시\놀라운한국어500_해설집_통합본.html`·`놀라운 한국어 500 해설집\놀라운한국어500_해설집_통합본.html`(각 ~9.5MB)는 콘텐츠 내장형이라 렌네임에 안 깨지나, 최근 편집(부록1 숫자 등) 미반영 옛 버전. 전용 빌드 스크립트 없음 → 재빌드는 시간 소요로 나중에. 급하지 않음.

⚠️ 메모리 내 옛 파일명(예 `123~141 서술어 문법 부정.html`, `시제_2_과거형_A_규칙.html`, `부록 1 _ 숫자.html`)은 모두 위 새 이름으로 바뀜 — 마스터 셸 = **`3 123~141 서술어 문법 부정.html`**. 폴더 [[project_canonical_folder]], 부록 [[project_appendix_series]].
