부록 1 숫자(`부록 1 _ 숫자.html`)의 모든 표는 **3색 의미 규칙**으로 통일(2026-06-16):
- **분홍** = 숫자·기호·식 (칸 `#fdf2f8`, 헤더 `#fce7f3`, 글자 `#9d174d`, 숫자 `#0f172a`)
- **연두** = 한국어 읽기 (칸 `#f7fee7`/`#edfacb`/`#e3f3c2` 3단계, 헤더 `#e9f7c5`/`#ddf2a8`/`#d0ea9a`, 글자 `#3f6212`)
- **회색** = 영어 뜻·중립 (칸 `#f8fafc`, 헤더 `#e2e8f0`, 글자 `#475569`/`#334155`). 테두리 `#cbd5e1`.

흐름: **분홍(수/기호) → 연두(한국어 읽기)**. s1~s7·symt(연산·기호 5열: 기호·연산=분홍, 이름·읽기=연두, 뜻=회색) 모두 적용. 예외: gstep 사용처 표(한자어/고유어 쓸 때)는 한자어=파랑/고유어=초록 별도.

특수박스: chunk-box=파랑(`#eff6ff`/`#2563eb`), ilrule(일 규칙)=맞음 초록(`#ecfdf5`)/틀림 빨강+취소선(`#fef2f2`,`<s>` `#dc2626`).

큰 수 표기 = 콤마(3자리 원위치)+슬래시(4자리 만단위) 동시(예 `12,34/5,678`), `/` 아래 만·억·조 라벨(`.msep`+`.munit` 0.5rem `#b45309`). 칸높이 `.numt td` padding `12px 5px`. 표기용 `/`·라벨은 참조표 읽기 셀에만, 받아쓰기·매칭 데이터는 콤마 그대로(채점 무영향).
