All 불규칙 (irregular-conjugation) lessons (ㄹ 436~440, ㅡ/으 441~444, 르 445~448, ㅂ 449~453, ㄷ 454~459, ㅅ 460~461) use ONE uniform derivation format in both per-sentence explanation cells AND the gstep table:

`어간 + 었/았습니다 → 변환된 어간 + 었/았습니다 → 최종형`
- ㄷ: 듣다: 듣 + 었습니다 → 들 + 었습니다 → 들었습니다
- ㅂ: 덥 + 었습니다 → 더우 + 었습니다 → 더웠습니다 (앞 모음 ㅗ면 오: 돕 + 았습니다 → 도오 + 았습니다 → 도왔습니다)
- ㅡ/으: 아프 + 었습니다 → 아프었습니다 → 아ㅍ았습니다 → 아팠습니다
- 르: 자르다: 자 + ㄹ랐습니다 → 잘랐습니다 (부르다: 부 + ㄹ렀습니다 → 불렀습니다)
- ㅅ: 짓다: 짓 + 었습니다 → 지 + 었습니다 → 지었습니다
- 규칙/예외 동사는 2단계: 입 + 었습니다 → 입었습니다 (ㅂ 유지)

**How to apply:** gstep1 gets a "만드는 과정" table (`기본형 | 만드는 과정`, 또는 ㄷ처럼 기본형/어간+어미/변환/최종형 4열). Drop the old `X → 변환 → 최종 (라벨)` arrow format and redundant idiom/English glosses. **Why:** shows the consonant/vowel change step-by-step, consistent across every 불규칙. Extends [[feedback_irregular_step_arrows]]. 자모 변화는 [[feedback_jamo_change_color]]로 색강조. Applied 2026-06-03.
