**Korean explanations in this project MUST include an English translation, placed on the following line.**

**Why:** The user explicitly instructed this on 2026-05-28 while reviewing the ~(으)러 가다 grammar summary — a Korean-only explanation ("왜? 시제는 문장 끝 동사에만 표시됩니다…") was flagged and English had to be added below it. The project is bilingual study material; learners rely on both languages.

**How to apply:**
- For any 한국어 설명 (Korean explanatory text) — grammar notes, rules, callouts, blockquotes, explain-notes — write Korean first, then immediately below add the English equivalent.
- Use a line break (`<br>`) followed by `<em>...</em>` or `<small><em>...</em></small>` for the English on the line below the Korean.
- **Exception:** In 문장 해설 (sentence-level explanation tables — the per-sentence "Explanation" column with Korean morphological breakdowns like `춥다 → 춥 + 으니까 → 추우니까`), Korean alone is acceptable. These are mechanical conjugation steps, not full explanations.
- Applies to: gstep blocks, explain-notes, callout boxes, blockquotes, subtitle text — anywhere prose-style Korean appears.
- **문법 정리(gstep) 안의 모든 한국어에 영어 필수 — 예시 표 포함.** gstep-table/gstep-pattern의 예시(한국어 문장·구·단어, 카테고리 라벨 등)도 영어 해석을 단다: 문장 예시는 `<br><small>(English)</small>`로 아래줄에, 단어 나열은 `단어 <small>(meaning)</small>` 인라인 또는 아래줄 영어 요약. (2026-05-31 명사형 384~387 표: "한국어를 공부하는 것은 재미있어요 → (Studying Korean is fun)", "말하기/듣기… → speaking/listening…" 적용.) 즉 문법 정리에서 영어 없는 한국어 칸은 없어야 함.
