부록(Appendix, Part VII)을 **8개 인터랙티브 해설 레슨**으로 제작(2026-06-15 착수 결정). 시제/조사 시리즈와 같은 마스터 템플릿 형식(Grammar Overview gstep + 종합표 + Writing Test + Look&Speak 플래시카드 + Sentence Matching + 객관식/타이핑 퀴즈).

**기준 셸 = `3 123~141 서술어 문법 부정.html`** (= "이미 나온 2과". 이 파일을 공통 셸 기준으로 삼고, 부록 2번은 이걸 재사용/리브랜딩만).

기존 A4 인쇄용 부록 파일(`부록 1~8 _ *.html`, 10~14KB)은 폐기하지 않고 **각 레슨의 표 본문 콘텐츠 원천**으로 흡수.

8과 구조 (테마색 / 패턴):
- 1 숫자(파랑) — 고유: 한자어/고유어 체계 + 숫자 레퍼런스 + 숫자 퀴즈
- 2 부정법(녹색) — ✅ 123~141 재사용
- 3 격식체·구어체·문어체(앰버) — 고유: 3시제×3문체 매트릭스 + 변환 연습
- 4~7 기초문법연습 01~04(보라) — **공통 템플릿 1벌**(가다·먹다·하다·좋다 활용 그리드 + Writing Test), 4과가 파일럿
- 8 기초문법총정리(분홍) — 고유 캡스톤: 마스터 문법맵 + 영역별 복습 + 종합 퀴즈

제작 순서: 4과 파일럿(검수) → 5~7 복제 → 1·3 고유 → 8 캡스톤(마지막) → 2 리브랜딩 → 목차 8과 인덱스 재작성. **명명(2026-06-16 확정): 완성된 인터랙티브 파일은 옛 인쇄본과 같은 띄어쓰기 형식 `부록 N _ 주제.html`. 대체된 옛 A4 인쇄본은 `마스터-템플릿-적용본\_원본 인쇄본\`으로 이동(삭제 아님, 보존).** 폴더 [[project_canonical_folder]]. (작업 중 임시 파일은 `부록_N_…` 밑줄로 만들고 완료 후 띄어쓰기로 변경.) 시제=[[project_tense_series]], 조사=[[project_particle_series]] 관례 준용.

**3과 완성(2026-06-16): `부록 3 _ 격식체 구어체 문어체.html`.** 앰버(`title-block other`) 테마, gstep/매칭게임 앰버 오버라이드. 원본 21단어×3시제×3문체 매트릭스 100% 보존(`STYLE_M` 배열→`.stylem` 표, 시제그룹색 현재파랑/과거초록/미래앰버, 가로스크롤+sticky 단어열). gstep: ①세 말투 개요표 ②문어체 현재형 품사별(동사 -ㄴ다/는다, 형용사·이다 기본형). 연습은 사용자 요청으로 **시제 파일 구조**로 재편(2026-06-16): **직접 만들기 + 퀴즈1 플래시 + 퀴즈2 쓰기**. 직접만들기·쓰기는 단어별 **9개 형태(문체 격/구/문 × 시제 현/과/미) 3×3 그리드 카드**(8단어=가다·먹다·오다·듣다·다르다·쉽다·하다·이다, STYLE_M에서 파생). 공용 `sg` 엔진(sgCheck/sgGrade/sgRevealAll/sgRevealShow/sgRevealCard/sgReset, "/" 복수정답 허용). 직접만들기=전체정답+카드별 ✓정답(reveal), 쓰기=채점+정답+%. 플래시=현재형 3문체 대조 12카드. 매칭게임 제거(emPairs=[]). ㎞→㎢ 수정은 1과만.

**3과 연습 재편(2026-06-22, 현재 파일명 `4 부록 3 격식체 구어체 문어체.html`):** 직접만들기·쓰기(sg엔진 mkBox/wrBox) **제거** → **문체별 연습 3구획**(① 격식체 ② 구어체 ③ 문어체, 각 8단어×현재·과거·미래)으로 교체. 입력이 아닌 **"?" 가리기**(q-cell/q-text/q-ans, qReveal/qHide/qAll) 방식. 데이터 인덱스 격식체[1,4,7]·구어체[2,5,8]·문어체[3,6,9]. 매트릭스·플래시는 비교 앵커로 유지. **"첫 행 예시" 패턴**([[feedback_first_row_sample]]) 통일 적용 = 부록 1·2·3·4 모든 "?" 표의 첫 행(가로표는 첫 열)을 정답 공개 예시로 둠.

**1과 완성(2026-06-15): `부록 1 _ 숫자.html`.** 파랑(`title-block sentence`) 테마, gstep/끊어읽기 박스 블루 오버라이드. 원본 7섹션(S1~S7) 데이터 100% 보존 + 7색 파스텔 참조표(.numt s1~s7). 학습보조: 한자어/고유어 사용처표·"네 자리 끊어읽기" 시각도구·시(hour) 앞 형태변화 노트. 연습=Look&Speak 12카드+받아쓰기(wt 기계, 18문항)+숫자매칭 10쌍. 주의: 원본 `100,210㎞`(㎞)와 읽기 `제곱킬로미터`(㎢) 불일치 — 원본 그대로 유지(미수정, 사용자 판단 대기). 개수 분류사는 1과 제외(8과로).

**4과 파일럿 완성(2026-06-15): `부록 4 _ 기초문법연습 01.html`.** 조립 방식 = `head -n 383`(123~141의 CSS+컨테이너) + 새 본문 + `tail -n +1877`(스크립트: speakKorean/wt*/em*/celebrate*). predicate(보라) 테마. 본문은 **데이터 기반 생성**: `DRILL` 배열(18어미 × 가다/먹다/하다/좋다, 형용사 N/A는 "*")로 종합 활용표(읽기)+쓰기연습(neg-test 기계, 63칸) 동시 생성, `LS` 배열로 Look&Speak 12카드, `emPairs` 10쌍 매칭. **5~7과는 이 파일 복제 후 DRILL/LS/emPairs 배열만 교체하면 됨.** 쓰기연습은 기존 negCheck/negGrade/negReveal(.neg-test+wtNormalize 의존) 재사용.

**기초문법연습 1~4 완성(2026-06-23).** 01 재구성 + 02~04 신규 빌드. 템플릿 문서 = `마스터-템플릿-적용본\_기초문법연습_템플릿_문서.md`(이 구조의 정본 스펙). 파일명: `4 부록 4~7 기초문법연습 01~04.html`.
- **01 재구성**: ① "Grammar Overview · 문법 정리" gstep **삭제** ② 헤더 `title-ko-sub` 삭제 ③ h2 `종합 활용표 · Conjugation Reference`→**`기초 문법 연습 1`**(부제목 삭제) ④ 기준단어 헤더 밑 영어(`go · V` 등) 삭제(한국어만) ⑤ "어미"열→**힌트 · Hint**, 의미 칸 군더더기 정리(현재 평서→현재, 의향→청유 의문, 청유 부정 의문→청유 의문 부정, "예시" 마커 삭제) ⑥ **"?" 가림**을 힌트(td.e)+활용형(td.v/td.a)에, **종합 활용표 AND Writing Test 둘 다** 적용(q-cell 초기화가 refBody의 td.v/td.a/td.e + drillBody의 td.e 래핑).
- **02~04 빌드**: 01 복제 후 `DRILL`/`LS`/`emPairs`·제목(N)·점수·부제목만 교체(PowerShell `-replace '(?s)var DRILL = \[.*?\];'`). 데이터는 옛 A4 인쇄본에서 추출. **02**=희망·계획·결정·허락·금지·의무·면제·부탁·경험(19행/62), **03**=위한행동·변화·모달어미+시간연결(18행/51), **04**=범위·원인6·목적·조건·양보·명사화·부사화·동사화(20행/69). 옛 A4 4개는 **`_원본 인쇄본\…(A4 인쇄본).html`** 로 이동(보존).
- **섹션 재배치(2026-06-23) — 1~4 전부**: 순서 = 종합표(기초 문법 연습 N) → **1. Look & Speak → 2. Sentence Matching → 3. Writing Test**(맨 끝, 초록 박스 h3→평범 h2로 번호 통일). ⚠️ Writing Test를 끝으로 옮기면 `drillBody`가 `DRILL` 생성 스크립트보다 뒤로 가 **빈 표**가 되므로, 생성 `<script>`도 표 뒤(footer 앞)로 함께 이동해야 함(q-cell "?" init보다는 앞).

**부록 8 기초문법총정리 검사·정리(2026-06-23).** 아직 **옛 A4 "마스터 문법 맵"**(주어·부사어·목적어·서술어 + 기타, 한 페이지 종합) — 인터랙티브화는 미정(방향 결정 대기: 리스타일 / 맵+?+퀴즈 / 보류). 내용 검사 후 ① 격식체·표기 5건 수정(★동일→★도, 추측·필수조건 격식체화, 시간 예 구로, 간접화법 청유 ~자고) ② **500 본문에 없는 5건 제거**(든지/바람에/로서(자격 박스)/군요/about(쯤·약·정도·가량)) — grep로 `3 *` 파일 부재 확인. 유지: 덕분에·탓에(원인 307~315), 려면(필수조건 356~361), 종별사·빈도부사 등 레슨 있는 항목. 제목 "5." 잔재·footer 페이지번호는 인터랙티브화 때 정리 예정.
